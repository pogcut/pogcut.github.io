# PogCut

**PogCut turns Twitch VODs into ready-to-post vertical highlight clips** (1080x1920, 60fps, word-by-word captions, titles and hooks) for TikTok, YouTube Shorts and Instagram Reels.

Website: **[pogcut.github.io](https://pogcut.github.io/)**
